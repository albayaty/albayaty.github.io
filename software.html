My Software

  1. Shell scripts for AIX UNIX server: Protects and reduces the commands for the disk array clusters and Oracle database in the ZTE Zsmart billing system.
  2. NE Pinger: Checks the availability of the desired networking entities (NE) and Oracle services for the ZTE Zsmart billing system.
  3. AuC File Generator: Generates a customized authentication file for the subscribers of the ZTE-HLR system.
  4. Blocker: Blocks the services of 10K subscribers in the ZTE-IN system using Windows automation and JavaScript.
  5. IN2Billing File Formatter: Converts designated file formats between the ZTE-IN and Zsmart billing systems.
  6. PDSN Checker: Checks the availability of the desired routers, firewalls, and Internet connectivity for the ZTE-PDSN system.
  7. KILLnREBOOT: Stops OMC-S service and its Java processes/dependencies, then restarts the overall Telecom systems (ZTE-BSC, MSC, HLR, PDSN, and AAA servers).
  8. Mass Provisioning: Generates a customizable XML file for the subscribers of the Alcatel-ngHLR system.
  9. FrameID Finder: Locates, filters, and displays a defined set of ERRORs in the Alcatel-ngHLR system.
  10. Web Automator: Checks and fills the required fields of web pages using Windows automation that are used in different services and entities for Telecom applications.
  11. Intranet Chat: Simple and secure Client-Server messenger for our private working domain.
  12. Predictive Imaging Software: A simplified plastic surgery tool uses the software-defined approach of directive instructions from plastic surgeons.
  13. RTP (Radiotherapy Planning) Technology Tool: Illustrates different biomedical engineering systems and their functions using MATLAB, at the Continuous Education Department, Al-Nahrain University.
  14. Steganography: Retrieves hidden information from image files, for the "CS610: Intermediate Programming/C" graduate class.
  15. ACL and E-mail Filters: Implements access lists, permissions, and filters for files and e-mails using Bash and Python scripting, for the "CS652: Script Programming for Network Administration" graduate class.
  16. Encryption: Implementation of the S-DES block cipher algorithm, for the "EE656: Hardware Description Language" graduate class, using VHDL with Xilinx FPGA, and for the "CS634: Cryptography and Data Security" graduate class as well, using Sage.

  17. Huffman Coding: Illustrates Binary Tree applications using C++, for the "CS620: Data Structures" graduate class.

    Ali Al-Bayaty. Huffman Code. (2014). GitHub, Inc. [Online]. Available: https://github.com/albayaty/Huffman-Code.git

  18. Video Game Engine: Designs and implements a game engine with sets of 2D objects and spirits using VHDL and C with Xilinx FPGA and MicroBlaze emulated CPU, for the "EE659: System-on-Chip" graduate class.
